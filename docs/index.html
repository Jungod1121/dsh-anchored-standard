Restart Harness → the preset lands automatically → create a blank session and pick "Anchored Standard (experimental)". Make it the default via agent-presets.default: anchored-standard in settings.yaml. Prefer no bundle? Copy the repo's preset/ directory to ~/.dsh/.agent-presets/anchored-standard/ manually.

FAQ

常见问题

FAQ

这和直接开官方 Minimal 有什么区别？ How is this different from just using the official Minimal preset?

Minimal 全程只有 2 个工具，干不了多文件工程（没有 glob/grep/edit/子代理/网页搜索）。本预设只借用它的「开局」，首个信号后展开全部 25 工具——Minimal 的脑子 + Standard 的手脚。

Minimal keeps only 2 tools for the whole task — no glob/grep/edit/subagents/web search. This preset borrows only its opening; after the first signal all 25 tools appear. Minimal's brain, Standard's hands.

我能不能手动「先用 Minimal、中途切 Standard」达到同样效果？ Can I just switch from Minimal to Standard mid-task manually?

不能。中途切换 preset 会破坏会话，而且新 preset 会话的首轮又是全工具目录——锚定就丢了。两阶段必须发生在同一个会话、同一个请求流里，这正是本预设做的事。

No. Switching presets mid-session breaks it, and a fresh Standard session would open with the full catalog again — the anchor is gone. The two phases must happen inside one session and one request stream, which is exactly what this preset does.

换台机器 / 换 V4 Flash 有用吗？ Does it work with other models, like V4 Flash?

V4 Flash 跨 harness 泛化更稳，风格会变、分数不变，用不上这套。锚定增益目前只在 V4 Pro 上被观测到，且评测证据是 n=2 单题。

V4 Flash generalizes across harnesses (style changes, scores don't), so it doesn't need this. The anchor gain has only been observed on V4 Pro, with n=2 single-task evidence.

装完后悔了怎么卸？ How do I uninstall?

dsh plugin --profile web remove dsh-anchored-standard 卸载 bundle；再 to remove the bundle, then rm -rf ~/.dsh/.agent-presets/anchored-standard 删除预设目录。to remove the preset directory.
